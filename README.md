# Broader Horizons

A single-page website for finding Vanderbilt summer opportunities: research programs, Maymesters, internships, fellowships and travel funding. Search by subject, browse by category, view the Maymester map, save and share each opportunity.

- `index.html` is the whole site (HTML, CSS, JavaScript and the data in one file).
- To view it locally, open `index.html` in a browser.
- To host it, enable GitHub Pages (Settings, Pages, deploy from the main branch, root folder).

Visit and click tracking only works when the page runs inside Claude as a published artifact. On GitHub Pages those calls are skipped and the site still works.
